# Reference fixes

These are hand-written fixes for the four benchmark cases. Each one transcribes the fix described in
that case's catalog `goal` (`src/verifix/agent_harness.py`). They are the ground truth for the
pre-registered overfitting experiment (`docs/experiments/C9_PREREGISTRATION.md`). They are not
agent output, and they are not used anywhere in the agent's prompts.
