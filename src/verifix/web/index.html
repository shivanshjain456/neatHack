Agent Ready

Give Claude Code, Cursor, Codex or your own agent this one line:

Read https://shivanshjain456.github.io/neatHack/agent.md and follow it.

Or install the CLI and drive it directly — every command speaks JSON:

pip install git+https://github.com/shivanshjain456/neatHack
verifix run --case case_01_ledger_rounding --mode graph_guarded --json
  1. Install

    pip install from the repository; the verifix CLI lands on PATH.

  2. Preflight

    Offline commands need no keys; live runs need one provider key.

  3. Run guarded

    graph_guarded mode maps callers before patching.

  4. Read the JSON

    status, rollbacks_executed, caller_regressions_caught.

  5. Resume if paused

    INTERRUPTED_CHECKPOINTED resumes from the WAL checkpoint.

  6. Cite receipts

    Quote benchmarks/receipts by sha256, never from memory.
